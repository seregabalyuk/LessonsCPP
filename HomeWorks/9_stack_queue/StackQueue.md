# Stack

Стет это структура данных, которая имеет большое значение в теории алгоритмов.
Он устроен очень просто:

```c++
#include <stack>

// какой-то код

std::stack<int> a;

// основные команды
a.emplace(10); // положить в конец стека
a.top(); // получить последний элемент
a.pop(); // удалить  последний элемент

// стандартные функции
a.size(); // размер
a.empty(); // пустой или нет

std::stack<int> b;

swap(a, b); // меняет местами содержимое стеков, очень быстро
```

На самом деле стек это не самостоятельный контейнер.
Под капотом у него лежит `deque`.

Так же можно положить другой контейнер.
```c++
stack<float, vector<float>> stk_vec;
```

# Queue

Очередь это структура данных, которая тоже имеет большое значение в теории алгоритмов.
Она устроена тоже очень просто:

```c++
#include <queue>

// какой-то код

std::queue<int> a;

// основные команды
a.emplace(10); // положить в конец стека
a.front(); // получить первый элемент
a.back(); // получить последний элемент
a.pop(); // удалить первый элемент

// стандартные функции
a.size(); // размер
a.empty(); // пустой или нет

std::queue<int> b;

swap(a, b); // меняет местами содержимое стеков, очень быстро
```

Очередь это тоже не самостоятельный контейнер.
Под капотом у него лежит `deque`.

Так же можно положить другой контейнер.
```c++
queue<float, list<float>> que_vec;
```
